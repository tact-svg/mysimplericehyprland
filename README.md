# mysimplericehyprland
this hyprland rice was made on arch.
i also used an app called hyprmod. its a settings app with a GUI, its very useful, i used it to setup my keybinds and to make waybar, dock and waypaper auto start without touching any config files.you can install it with AUR.
to make the logos of waybar work you must install ttf-jetbrains-mono-nerd.
to make kitty and waybar work, you need fish shell by installing it with pacman, and minecraft fonts with this command: yay -S minecraft-ttf-git
